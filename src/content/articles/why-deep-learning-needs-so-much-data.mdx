## More parameters, more room to get it wrong

A deep neural network can have millions of adjustable parameters. Each parameter is a small dial the model can turn to fit the training data better. With that many dials, a model can fit almost any small dataset perfectly, including its noise and quirks, without learning anything generalizable. Large datasets give those millions of dials enough real signal to tune toward, instead of toward coincidences in a small sample.

## Data teaches variation, not just answers

A model doesn't just need examples, it needs examples that vary in the ways the real world varies. If you're training an image classifier and every photo of a cat happens to be taken indoors, the model might quietly learn "indoor lighting" instead of "cat." More data, collected with more variety, is often what breaks these shortcuts, because the spurious pattern stops being reliable across enough examples.

## Why small data pushes you toward simpler models

When you don't have much data, a simpler model with fewer parameters is usually the safer choice. It has less room to memorize coincidences and more pressure to find patterns that genuinely hold. This is one reason experienced practitioners often start with logistic regression or a small decision tree before reaching for a deep network, even when deep learning is fashionable.

## What helps when data is limited

There are ways to reduce the data hunger of deep learning: starting from a model pretrained on a related, larger dataset, generating synthetic variations of existing examples, or simplifying the architecture to use fewer parameters. None of these replace good data entirely, but they narrow the gap when collecting more isn't realistic.

## The practical lesson

If a deep learning project is underperforming and the architecture seems reasonable, the first question worth asking isn't "what model should I try next." It's "do I actually have enough varied, clean data for the model I'm already using." Most of the time, that's where the real bottleneck is hiding.
